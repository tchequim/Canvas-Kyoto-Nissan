Plan de acción

Conexión en vivo: pegá arriba la URL del Web App de Apps Script y elegí un intervalo — el dashboard se actualiza solo desde tu Google Sheet, sin descargar nada. Lee las hojas Ventas - Mensual, Posventa - Mensual, Verbalizaciones y las hojas Plan de Accion de cada sucursal. La conexión en vivo funciona con el archivo abierto localmente o alojado en GitHub Pages (no desde el link de Claude, que bloquea sitios externos por seguridad). También podés cargar un .xlsx a mano. Training se alimenta de un segundo Google Sheet (el de Academia): pegá su URL en “URL Training”. La línea vertical negra en cada barra marca el objetivo Nissan.
